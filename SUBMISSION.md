# Сдача тестового задания

## Что реализовано

Проект реализует требуемый сценарий для Telegram через GREEN-API:

1. Пользователь открывает веб-чат.
2. Вводит `idInstance` и `apiTokenInstance`.
3. Вводит номер Telegram-получателя.
4. Приложение вызывает `CheckAccount` и получает `chatId`.
5. Создаётся чат.
6. Текст отправляется через `SendMessage`.
7. Входящие текстовые сообщения читаются через `ReceiveNotification`.
8. После обработки вызывается `DeleteNotification`.
9. Ответ собеседника появляется в интерфейсе автоматически.

## Стек

- React 19
- Vite 7
- Node.js
- Express 5
- GREEN-API Telegram API
- CSS без UI-фреймворка

## Архитектурное решение

React отвечает за интерфейс и состояние чата. Express используется как небольшой proxy-слой между браузером и GREEN-API.

Такой подход позволяет не хранить credentials в исходном коде и не отправлять запросы к GREEN-API напрямую из компонентов React.

## Перед отправкой

1. Добавить собственное резюме PDF.
2. Создать GitHub repository и загрузить проект.
3. Проверить `npm install` и `npm run build`.
4. Проверить полный сценарий на реальном Telegram-инстансе GREEN-API.
5. При наличии — добавить URL онлайн-версии и короткого видео.
6. В письмо работодателю добавить Telegram для связи и предпочтительный формат работы.
